# Vane & Volume Bookstore

A fictional independent bookstore website I made for Web Development I.

I used HTML and CSS to create four pages: Home, Shelves, About and Events. I also worked with JavaScript for the mobile menu and a practice shopping cart.

The cart saves its items in the browser using localStorage. The newsletter, contact and donation forms are demonstrations. They don't send messages or take orders.

## Files

- `index.html` — homepage
- `gallery.html` — books, magazines and other items
- `about.html` — shop information and contact form
- `custom.html` — events and donations
- `styles.css` — page layouts, colors and responsive styles
- `script.js` — menu, cart and form interactions
